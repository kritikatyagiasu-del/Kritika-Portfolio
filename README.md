# Kritika Tyagi — Interactive Portfolio

**Live site:** https://kritikatyagiasu-del.github.io/Kritika-Portfolio/

A single-page, interactive portfolio for Kritika Tyagi — Product Manager focused on Agentic AI, Master Data Management, and GTM strategy. Built as a self-contained HTML/CSS/JS app, sourced from a Notion page and designed to let hiring managers explore experience, skills, and project case studies directly in the browser.

## Features

- **Accordion sections** — Skillset, Experience, Education, Impact, Projects, References, Interests, and Contact, each expanding smoothly with no page reloads
- **Expandable project case studies** — the four professional projects (Data Migration, Agentic AI for Account Planning, CRM Integration with ERP, Year-End Sales Realignment) each open into a structured breakdown: role, objective, problem statement, key achievements, impacted users, challenges, trade-offs, solution approach, and resources used
- **Scroll-synced side navigation** — a left-hand rail tracks which section is in view and jumps to any section on click
- **Light/dark theme support** — follows the visitor's system preference automatically
- **Ambient hero animation** — a lightweight canvas node network in the header (respects `prefers-reduced-motion`)
- **Fully responsive** — down to mobile widths

## Tech

Plain HTML, CSS, and vanilla JavaScript — no build step, no framework, and no external runtime dependencies beyond Google Fonts (Fraunces, IBM Plex Sans, IBM Plex Mono). Everything lives in a single `index.html` file, served directly via GitHub Pages.

## Content source

Portfolio content (bio, skills, experience, projects, metrics, and references) is maintained in Notion and periodically synced into this file.
